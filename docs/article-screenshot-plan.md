# Sarthi Technical Article: Screenshot Plan

This document outlines the recommended screenshots for the technical article, specifying their visual focus, technical features demonstrated, placement within the narrative, and key takeaways for readers.

> **Publishing note**: When publishing the article and LinkedIn post, tag Code.in as required by the submission guide.

## Screenshot 1: Sarthi Web Interface & Mandi Dashboard

- **File / Source**: `docs/screenshots/desktop-home.png` (or live capture at `http://localhost:5173`)
- **What Screen Is Captured**: The desktop dashboard showing the navigation sidebar, district soil baseline (702-district Ground Truth), live APMC Mandi commodity rates, active weather advisories, and the memory count badge in the header.
- **Feature Demonstrated**: Voice-first multimodal agricultural interface grounded in authoritative Government of India datasets paired with a long-term memory indicator.
- **Placement in Article**: In Section 1 (Introduction / Problem Statement), right after explaining why stateless chatbots fail rural farmers.
- **Reader Takeaway**: Sarthi is not a generic text chatbot; it is a full-featured agricultural platform with localized district soil context, live market rates, and persistent farmer identity.

## Screenshot 2: Memory Dashboard ("What I Remember")

- **File / Source**: Web application Memory tab (`page === "memory"`, component `MemoryScreen` in `frontend/src/App.tsx#L870-L895`)
- **What Screen Is Captured**: The 4-card memory overview grid displaying:
  1. *Farm Profile* (soil type, acreage, district)
  2. *Working Preferences* (low-water crops, organic inputs)
  3. *Past Experience* (historical crop yields and failure events)
  4. *Learned From You* (borewell limits, authoritative farmer corrections)
  Along with the "How Advice Has Evolved" timeline and the "Teach Sarthi" direct input button.
- **Feature Demonstrated**: Transparent memory visibility and user control over agent knowledge, powered by [Hindsight](https://github.com/vectorize-io/hindsight).
- **Placement in Article**: In Section 3 (Hindsight Architecture & Implementation), illustrating how long-term memory is structured, categorized, and inspected by the farmer.
- **Reader Takeaway**: Farmers have complete visibility into what the AI remembers about their farm. Memory is transparent, inspectable, and editable, not an opaque black box.

## Screenshot 3: Memory-Aware Recommendation & "Why This Recommendation?" Card

- **File / Source**: Web application AI Assistant screen (`frontend/src/App.tsx#L340-L380`, component `MemoryInfluenceCard`)
- **What Screen Is Captured**: A crop advisory card showing the badge `🧠 Personalized using your past experience (2 memories recalled)` and the expanded reasoning panel revealing the specific constraint (borewell runs 1 hour/day) and past crop failure (tomato failed due to water shortage) that shaped the recommendation.
- **Feature Demonstrated**: Transparent reasoning and structured memory influence metadata generated by `MemoryAwareRecommender.build_memory_influence_metadata()`.
- **Placement in Article**: In Section 4 (Recommendation Reasoning & Before/After Impact).
- **Reader Takeaway**: [Hindsight](https://github.com/vectorize-io/hindsight) memories directly change the agricultural advice given to the farmer, preventing catastrophic repeated failures through explainable reasoning.

---

## Screenshot 4: Live Side-by-Side Comparison (Before vs. After Memory)

- **File / Source**: Live execution of `/api/memory/compare` endpoint (or live interactive comparison card in the web interface)
- **What Screen Is Captured**: Side-by-side comparison showing:
  - *Without Memory (Generic Advisory)*: Recommends water-thirsty tomato based strictly on current season and weather data.
  - *With Hindsight Memory (Personalized Advisory)*: Warns against tomato due to recorded borewell limitations and previous crop loss, recommending drought-hardy bajra and groundnut instead.
- **Feature Demonstrated**: Direct empirical demonstration of agent memory altering decision outcomes using real Azure OpenAI GPT-4o-mini and Hindsight Cloud retrieval.
- **Placement in Article**: In Section 5 (Empirical Results & Demonstration).
- **Reader Takeaway**: Agent memory is the difference between disastrous, generic recommendations and realistic, personalized agronomic advice.
